# Hello application template

Copyable frontend-only app using public @usecloud packages. It does not import
Core internals or depend on Core's React runtime. Build with npm run build, copy
dist under staging/frontend with manifest.yaml at staging root, then use the
package tooling described in docs/apps/first-app.md.

The example demonstrates theme inheritance, generic UI, host navigation and a
version-qualified Custom Element. It intentionally has no backend/permissions.

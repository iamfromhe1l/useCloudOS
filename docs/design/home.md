# Desktop Home

Named twelve-column layout: server 5/resources 7, storage 4/apps 4/system 4.
One 16px gutter and bounded 1280px desktop. Medium uses logical two columns;
compact stacks. Test actual computed named areas: malformed rows must never
silently collapse widgets into one implicit cell.

Identity is a primary-container hero, resources are glanceable metrics,
storage uses tertiary capacity, applications use real registry counts/status,
system keeps technical information compact. This is not monitoring/Grafana.
No invented chart histories or Docker query inside Core.

App launchers sit directly on wallpaper, use canonical registry identity and
single click/tap. Right-click plus keyboard/touch action menu offers Open and
management. No Applications megacard, marketing slogan or fake app list.

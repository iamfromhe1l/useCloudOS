# Files application

Core window → path/toolbar → efficient list → capacity/count footer.
Breadcrumbs scroll for deep paths. Filter explicitly scopes to loaded files,
not a pretend full-server search. View menu owns sort radios and hidden toggle.
New folder and Upload are real capability-gated actions.

Aligned desktop name/size/modified columns become touch-friendly compact rows.
Single file selection colors the row; folders open on one click. Long names
truncate with full text/title. Every object has ⋯ and Radix ContextMenu from one
private domain action model. Delete uses AlertDialog, rename/move use Dialog.

Initial Skeleton, retained background data, local real upload progress/cancel,
empty/error/read-only/permission states are mandatory. No literal Actions label
on every row, oversized sort selector, hover-only action or CSS leak into Core.
List is server-paged; filter only affects the currently loaded page. No recursive
copy, previews or trash are implied by this redesign.

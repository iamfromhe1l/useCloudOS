# useCloudOS Personal Cloud Shell

The frozen baseline is [Design Contract](README.md). Before any frontend visual
work, read its linked foundations, shell, component, responsive, performance
and architecture documents.

The desktop metaphor comprises static wallpaper, independent system bar,
desktop widgets and icons, maximized application windows, launcher dock and
utility panels. Material You provides full semantic role pairs in both themes.
end-4 informs compact utility density; personal-cloud simplicity constrains
interaction and hierarchy.

The application registry is the single identity source. The FSD layer contract
and ESLint checks prevent visual primitives from becoming coupled to feature
logic. Radix supplies behavior; useCloudOS owns composition and styling.

There are no marketing headings, website navigation bars, native color
pickers or production mock data. Unsupported applications remain visibly
labelled Coming later.

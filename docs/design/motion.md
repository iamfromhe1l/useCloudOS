# Motion

Fast 120ms, standard 180ms, entry 220ms maximum. Animate opacity/transform and
short tonal state changes. Menus fade/scale from 0.97. Dock lifts at most 3px;
buttons press to 0.97. Never animate decorative layout dimensions or replay
row entrances after refetch.

No idle loops, ambient animated wallpaper, particles, parallax or animation
runtime dependency. Action-level Spinner rotates only while pending; reduced
motion removes rotation/translation. Real Progress changes only with measured
transfer progress. Blur is limited to Dock plus one utility panel, ≤12px and
disabled by reduced transparency.

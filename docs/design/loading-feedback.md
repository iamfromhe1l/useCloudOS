# Loading and feedback

Initial absence → contained Skeleton. Action pending → Spinner plus verb,
disabled duplicate submission and aria-busy. Measurable work → Progress only
with a real value. Never fabricate installation percentages/stages.

Background refresh retains valid data and selected state. Files preserves rows
across sorting/paging within the same path; a different uncached directory has
initial skeletons. Mutations invalidate queries without blanking unrelated data.
Upload owns local progress/cancel/error state. Error is local/actionable; empty
state explains the next valid action. No universal full-screen spinner.

Installer stays pending until registry invalidation resolves. Success becomes
Open from actual installed metadata, not a transient return to Install.

# Typography

Roboto Flex is UI; JetBrains Mono is technical IDs, ports, kernel and logs.
Material Symbols Rounded is the only functional icon family. Never use emoji.

| Role                   | Size/line height | Purpose                         |
| ---------------------- | ---------------- | ------------------------------- |
| Display                | 40/1.15          | Exceptional system moments only |
| Heading                | 24/1.25          | Desktop identity                |
| Title large            | 19/1.35          | Window/view identity            |
| Title medium / section | 16/1.4           | Section and object identity     |
| Body                   | 15/1.5           | General content                 |
| Body small             | 13/1.45          | Supporting metadata             |
| Label                  | 13–14/1.35       | Controls/modules                |
| Caption                | 12/1.4           | Secondary shell detail          |
| Technical              | 13–14/1.5        | Selective monospace             |
| Metric medium / large  | 34/1.1, 48/1.05  | Glanceable desktop values       |

Central CSS font shorthands and semantic Tailwind aliases define the scale.
No app-screen display H1. Long names retain full accessible text; rows truncate,
technical properties wrap anywhere, logs own bidirectional scroll.

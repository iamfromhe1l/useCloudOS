# Foundations · Design System 2.0

Material You is visible in color-role pairs, selection, expressive widgets,
personalization and shape hierarchy. OS character comes from independent shell
layers, window chrome, object menus and application content boundaries.

Density is contextual: compact shell chrome; expressive desktop widgets;
efficient file/service rows; comfortable grouped Settings; discoverable Store.
Do not impose bento on lists, logs or settings.

Read [color](color.md), [shape](shape.md), [spacing](spacing.md),
[typography](typography.md) and [motion](motion.md) for implementation tokens.
Tonal hierarchy precedes shadow. Only transient shell layers use bounded blur.
No idle animation or GPU wallpaper effects.

Roboto Flex, JetBrains Mono and Material Symbols Rounded remain local.
Icons are optical-size 24 by default, 16–20 in compact chrome, 32–40 for app
identity. Use consistent outlined weight 400 assets; fill is not a new icon set.
Large launcher treatment comes from a generated tonal tile, not a second icon.
